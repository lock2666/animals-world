# 🦁 عالم الحيوانات — موقع تعليمي تفاعلي للأطفال

موقع تعليمي عربي أحادي الصفحة لتعليم الأطفال عن الحيوانات ومواطنها الطبيعية، مبني بملف HTML واحد فقط (بدون أي مكتبات أو أدوات بناء).

## ✨ المحتوى

- **🐾 بطاقات الحيوانات** — 7 حيوانات (جمل، أسد، قرد، ضفدع، دب قطبي، وأصدقاؤهم) مع صور حقيقية ووصف مبسط لكل موطن.
- **🌈 فلترة حسب المواطن** — أزرار ملونة تعرض الحيوانات الداخلية فقط: الكل، الصحراء، السافانا، الغابة الاستوائية، السافانا، البركة والمستنقع، الجبال، المحيط والبحر، القطب الشمالي.
- **🧭 اختبار تفاعلي** — 6 أسئلة اختيار من متعدد مع تقييم بالنجوم وشاشة نتائج.
- **🧩 لعبة وصّل الحيوان بموطنه** — سحب وإفلات (مع وضع بديل بالضغط للأجهزة اللمسية)، اهتزاز عند الخطأ، وشاشة فوز مع خلط جديد عند الإعادة.
- **⚠️ حيوانات تحتاج مساعدتنا** — بطاقات للدب القطبي والأسد والقرد والضفدع تشرح تهديدات مواطنها وكيف يمكن للأطفال المساعدة.
- **🛡️ كيف نحمي مواطن الحيوانات؟** — 5 نصائح عملية مبسطة للأطفال.
- **🎉 مطر النجوم الاحتفالي** — تأثير جزيئات ملون عند النجاح في الاختبار أو إتمام اللعبة.

## 🚀 التشغيل

افتح ملف `index.html` بأي متصفح حديث — لا يحتاج تثبيت ولا خادم محلي ولا اتصال سوى لتحميل الصور.

## 🌐 النشر كموقع مباشر (GitHub Pages)

بعد رفع الملفات إلى المستودع:

1. من تبويب **Settings** في المستودع.
2. من القائمة الجانبية اختر **Pages**.
3. تحت **Build and deployment** اختر Source: **Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/ (root)** ثم اضغط **Save**.
5. خلال دقيقة سيصبح الموقع متاحاً على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
